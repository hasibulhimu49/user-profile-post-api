# User Profile Post API

Spring Boot REST API for managing users, profiles, and posts.

## Tech Stack
- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Lombok

## Features
- Create user
- Create profile for user
- Create posts under profile
- Get all and with Id
- Update
- Delete

## How to Run
1. Configure database in application.properties
2. Run the application
3. Import Postman collection

## API Documentation
See Postman collection in `/postman` folder.
